# Gmail סינון מתקדם

תוסף Chrome לסינון מתקדם ב-Gmail: בחירה מרובה של סוגי כוכב, מצב קריאה, תיקיות, תוויות, שולחים/נמענים וביטויים מדויקים, עם שמירת תבניות.

## התקנה
1. הורד את הקובץ `gmail-advanced-filter.zip` מעמוד ה-Releases (או Code → Download ZIP) וחלץ אותו לתיקייה קבועה.
2. פתח `chrome://extensions` והפעל **Developer mode**.
3. לחץ **Load unpacked** ובחר את התיקייה שחולצה.
4. רענן את Gmail.

## עדכון
הורד את הגרסה החדשה לאותה תיקייה ולחץ "רענון" ליד התוסף ב-`chrome://extensions`.

## הערה
סוגי כוכבים צריכים להיות מופעלים בהגדרות Gmail ← כללי ← כוכבים.
